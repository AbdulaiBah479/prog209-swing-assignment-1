# PROG209 Individual Assignment 1: Sunrise Studio (Java Swing)

**Author:** Abdulai Bah  |  **Module:** PROG209 Event Driven Programming

A Java Swing application: `SwingAssignment extends JFrame` with a constructor, a `JFrame frame` (title "Java Swing Assignment", 800x800, closes on X), a `JPanel panel` and a `JLabel label` ("Welcome to Java Swing First Individual Assignment by Abdulai Bah"), my own `ImageIcon` (`icon.png`), and a button that changes the label text and the panel colour.

## Extras
- Animated gradient sky, floating sun and three moving waves (Java 2D)
- Four moods with smooth colour fades (`javax.swing.Timer`)
- Live status line with mood, click counter and clock
- Menu bar: File (Reset, Exit) and Help (About)
- Keyboard: Enter or Alt+C press the button

## Run
Put `SwingAssignment.java` and `icon.png` in the same folder, then:
```
javac SwingAssignment.java
java SwingAssignment
```

## Files
- `SwingAssignment.java`: all source code
- `icon.png`: application icon
- `wireframe/`: wireframe (SVG for Figma import, and PNG)
- `docs/`: documentation (.docx) and screenshots
